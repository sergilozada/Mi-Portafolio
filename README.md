# Sergi Lozada | Portfolio

Este es mi portfolio personal como desarrollador de software. Lo he creado para mostrar mi forma de trabajar, las tecnologías que utilizo y algunos de los proyectos que estoy construyendo.

En lugar de una página estática, quería una experiencia con algo de personalidad: una escena 3D de teclado, animaciones al hacer scroll, temas inspirados en las estaciones del año y soporte en español e inglés.

## Este portfolio

El portfolio está construido con:

- [Next.js 16](https://nextjs.org/) con App Router
- [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) y [Three.js](https://threejs.org/) para la escena 3D
- [Tailwind CSS](https://tailwindcss.com/) para los estilos
- [Lenis](https://github.com/darkroomengineering/lenis) para el scroll suave
- TypeScript

También incluye un selector de idioma, cuatro temas visuales, modales de proyectos, animaciones de entrada y una versión adaptada para móvil.

## Ejecutarlo en local

Necesitas Node.js 20 o superior.

```bash
git clone https://github.com/sergilozada/Mi-Portafolio.git
cd Mi-Portafolio
npm install
npm run dev
```

Después abre [http://localhost:3000](http://localhost:3000).

Para generar la versión estática de GitHub Pages:

```bash
npm run build
```

## Estructura principal

```text
app/             Página principal, layout y estilos globales
components/      Escena 3D, navegación, modales y animaciones
lib/              Traducciones, temas y datos de tecnologías
public/projects/  Recursos visuales de los proyectos
public/sounds/    Sonidos de la escena del teclado
```
